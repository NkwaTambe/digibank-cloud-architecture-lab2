🔌 Sample Endpoints

  • POST /api/customers — create a customer
  • GET /api/customers — list customers
  • POST /api/accounts — create an account
  • POST /api/accounts/{id}/debit — debit an account
  • POST /api/accounts/{id}/credit — credit an account
  • POST /api/transactions — create a transaction
  • POST /api/transactions/transfers — execute a Saga transfer
  • GET /api/transactions — list transactions (CQRS read)
  • GET /api/compliance/validate/5000 — validate an amount
  • GET /api/notifications — list notifications
